# Motifs

Line-based shapes taken from the mark. One per surface, never behind text.

- `chevron.svg`: the carved chevron as a teal (#1ED7C9) stroke. Bullets in a sequence, the "next" affordance.
- `chevron-stream.svg`: three teal chevrons fading in from the left. Progress, loading and transitions; the static form of the ChevronLoader.
- `hexagon-outline.svg`: the mark as two offset teal outlines at partial opacity with a dashed #3A4870 crosshair. Title slides only, bleeding off the right edge on navy.
- `blueprint-grid-light.svg`, `blueprint-grid-dark.svg`: one 192px tile of the 48px blueprint grid (#E4E8EF on mist, #16214A on navy). Repeat it behind content slides.
