# Logos

The carved hexagon mark and the KubeSwift wordmark. Every file is a fixed-colour SVG with the wordmark converted to outlines, so it renders the same without Space Grotesk installed.

- `kubeswift-horizontal-light.svg`: mark and wordmark in azure (#15357E). Light grounds. The default.
- `kubeswift-horizontal-dark.svg`: white mark and "Kube", teal (#1ED7C9) "Swift". Navy and dark grounds.
- `kubeswift-stacked-light.svg`, `kubeswift-stacked-dark.svg`: the same, stacked, for square spaces and stickers.
- `kubeswift-mark-azure.svg`: the mark alone in azure. Favicons, slide corners on light.
- `kubeswift-mark-white.svg`: the mark alone in white. Slide corners on navy, the app icon on a navy tile.
- `kubeswift-mark-black.svg`: the mark alone in #0B0E1A, for single-ink print.

Clear space is the height of the carved chevron on every side. Minimum height 24px for the horizontal lockup, 16px for the mark.
