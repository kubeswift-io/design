# ChevronLoader

The carved chevron pulled out of the mark and repeated: three chevrons streaking forward, for loading, progress and transitions.

- Provide: nothing; give it `role="status"` and an `aria-label`.
- Variants: teal on navy by default; `.ks-on-light` drops the navy tile and draws the chevrons in `brand-ink` on bg.
- Motion stops under `prefers-reduced-motion`.
