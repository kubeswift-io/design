# ColumnHeader

The header of a column on a comparison or capability slide: a 2px rule in `ink`, an uppercase mono label in `accent`, and an optional tag.

- Provide: the label, optionally one Tag, then the column's body copy in `slide-body` and `sub`.
- Layout: two to four columns, `space-28` apart, all rules on one line.
- Don't put more than one tag on a header, or a sentence in the label.
