# Lockup

The KubeSwift mark with the wordmark, for page headers, slide corners and title slides. Prefer the SVG files in Logos for anything exported; use this HTML lockup where the page already loads Space Grotesk.

- Provide: nothing. Size it with `font-size` on `.ks-lockup` (the mark scales with it).
- Colours follow the theme through `brand-ink` and `brand-swift`. Add `.ks-on-dark` when the lockup sits on navy inside a light page (title bands, the app icon); `.ks-stacked` for square spaces.
- Slides: 26px mark top-right on content slides; 64px mark top-left on title slides.
- Do keep clear space equal to the chevron's height. Don't put it on teal, over the grid's dense areas, or over the hexagon motif.
