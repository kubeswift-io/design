# Tag

A short uppercase label for a maturity level, a platform or a version, next to a column header or inside a diagram.

- Provide: one to three words. The CSS uppercases them.
- Variants: `.ks-fill` (teal fill, `on-speed` text) for the one status that matters most on the slide, such as a validated or shipped state; plain for neutral facts; `.ks-dashed` in `accent` for early or experimental.
- Do use at most one filled tag per group. Don't put white text on teal, and don't use tags as buttons.
